# Database connection pool exhausted

## Symptoms

Requests to global-bank-account hang and then fail. The service log shows HikariPool-1 - Connection is not available, request timed out after 30000ms. Users say balances do not load and payments wait for a long time before they fail.

## Checks

Look at the pool metrics: active connections sit at the maximum and the pending count keeps rising. Find slow queries that hold a connection for a long time. Check for code that opens a connection and never closes it.

## Fix

Restart one pod at a time to free the stuck connections. Raise the pool size only if the database can accept more sessions. Fix the leak in code before the next release.

## Escalation

If pending requests keep rising after the restart, open an incident and call the database team.
