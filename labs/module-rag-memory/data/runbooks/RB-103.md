# Login latency above 2 seconds

## Symptoms

Sign-in to global-bank-authentication takes more than 2 seconds at the 95th percentile. Users say the login page spins before the dashboard appears.

## Checks

Check the token service response time and the user directory lookup time. Check the cache hit rate for user profiles. A cold cache after a restart makes every login read from the directory.

## Fix

Warm the profile cache with the warm-up job. If the directory is slow, move traffic to the second directory replica.

## Escalation

If latency stays above 2 seconds for 30 minutes, open a medium-severity incident for the identity team.
