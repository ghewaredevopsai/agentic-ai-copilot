# Certificate expiring within 7 days

## Symptoms

The certificate monitor raises an alert that a TLS certificate expires within 7 days. Nothing is broken yet. When the certificate expires, clients refuse the connection with a handshake error.

## Checks

Find which hostname the certificate covers and which ingress uses it. Check whether automatic renewal failed, and read the renewal job log.

## Fix

Renew the certificate through the certificate request portal. Load the new certificate into the secret and restart the ingress controller pods one at a time.

## Escalation

If renewal fails and fewer than 2 days are left, raise a change request with the security team.
