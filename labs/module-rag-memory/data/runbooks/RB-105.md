# Nightly batch job did not finish

## Symptoms

The end-of-day statement batch is still running at 06:00, or it stopped without writing its completion marker. Morning reports show yesterday's figures.

## Checks

Read the scheduler history for the job. Find the last step that finished. Check whether an input file arrived late from the upstream system.

## Fix

Restart the job from the failed step, not from the beginning. Running it from the start creates duplicate statement lines.

## Escalation

If the job cannot finish by 08:00, tell the operations desk so they can warn branch staff.
