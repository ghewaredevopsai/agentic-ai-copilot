# Disk usage above 90 percent on report nodes

## Symptoms

The disk alert fires on a report node at 90 percent. Report exports slow down, and at 100 percent they fail with No space left on device.

## Checks

Find the largest folders on the data volume. Old export files and rotated logs are the usual cause.

## Fix

Delete export files older than 14 days and compress rotated logs. Do not delete the current day's exports. If usage is still above 85 percent, ask the platform team to grow the volume.

## Escalation

If the disk reaches 98 percent, open a high-severity incident.
