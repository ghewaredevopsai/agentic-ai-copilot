# Ledger cannot reach the Oracle database

## Symptoms

The ledger posting service fails at start-up or during posting with ORA-12541: TNS:no listener. Postings queue up and account balances stop changing.

## Checks

Check that the database listener process is running on the database host. Check the connection string host and port in the ledger configuration. A failover to the standby database changes the host.

## Fix

Ask the database team to start the listener, or point the ledger at the standby host during a failover. Then restart the ledger service so it reconnects.

## Escalation

Postings that wait more than 15 minutes delay customer balances. Open a high-severity incident at once.
