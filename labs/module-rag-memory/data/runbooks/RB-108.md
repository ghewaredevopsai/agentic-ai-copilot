# Rules engine rejects valid transfers

## Symptoms

global-bank-rules rejects transfers that should pass, with the reason LIMIT_EXCEEDED, even for small amounts. Customers see the message Transfer declined.

## Checks

Check which rule version is live. Compare the daily limit table with the approved values. A rule deploy with a wrong currency setting is the usual cause.

## Fix

Roll the rules back to the last approved version. Re-deploy the fixed rule set only after a second person checks the limit table.

## Escalation

Tell the fraud and limits team, because they must review every declined transfer from the affected period.
