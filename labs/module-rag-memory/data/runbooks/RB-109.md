# Posting events are delayed in the message queue

## Symptoms

Consumer lag on the postings topic keeps growing. Transactions appear in the customer's history many minutes late.

## Checks

Check the number of consumers and whether any consumer is stuck on one message. A message that always fails blocks its partition.

## Fix

Move the failing message to the dead-letter topic and restart the stuck consumer. Add consumers only if every partition is busy.

## Escalation

If lag passes 10,000 messages, open an incident for the transaction team.
