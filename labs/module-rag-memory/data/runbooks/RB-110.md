# Customer document upload fails

## Symptoms

Customers cannot upload identity documents in global-bank-customer. The upload stops at 99 percent, or it fails with HTTP 413 Payload Too Large.

## Checks

Check the file size limit on the ingress and in the service. Phone cameras make large photos. Check that the virus scanner is running.

## Fix

Raise the ingress body size limit to match the service limit, which is 10 MB. If the scanner is down, restart it.

## Escalation

If uploads fail for more than one hour, tell the onboarding team so they can pause account opening campaigns.
