# Break-glass access to the production database

## Symptoms

An incident needs a direct query on the production database, and the normal read-only role is not enough.

## Checks

Confirm that a high-severity incident is open. Confirm that a second engineer will watch the session.

## Fix

Request the break-glass role in the access portal with the incident number. The role expires after 2 hours. Every command is recorded.

## Escalation

The security team reviews every break-glass session within one working day.
