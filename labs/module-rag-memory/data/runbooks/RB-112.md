# Pod keeps restarting after a config change

## Symptoms

A pod shows CrashLoopBackOff soon after a ConfigMap or secret change. The service is down or running on fewer replicas.

## Checks

Read the logs of the previous container. A missing setting or a wrong value in the new config is the usual cause.

## Fix

Revert the config change and restart the deployment. Then fix the value and test it in the staging cluster first.

## Escalation

If the service has no healthy replica, open a high-severity incident.
