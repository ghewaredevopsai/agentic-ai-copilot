# Transaction service runs out of memory

## Symptoms

Pods of global-bank-transaction restart with the reason OOMKilled, usually at month end when volumes are high.

## Checks

Compare memory use with the pod memory limit. Look for a large report or export request that loads everything into memory.

## Fix

Raise the memory limit for the month-end period, and page the report request instead of loading it all at once.

## Escalation

If pods restart more than 5 times in an hour, open an incident for the transaction team.
