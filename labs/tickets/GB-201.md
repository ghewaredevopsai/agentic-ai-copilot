# GB-201 — List postings for a client reference
<!-- labels: story, eval-set -->

**Type:** Story · **Priority:** Medium · **Repository:** global-bank-account

## Description

Operations need to see every posting recorded against a client reference. They use it to check what
happened when an upstream system reports a difference.

## Acceptance criteria

1. `GET /api/v1/postings?clientReference=X` returns all postings with that client reference.
2. An unknown reference returns an empty list, not an error.
3. Covered by tests.
