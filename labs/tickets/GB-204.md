# GB-204 — The posting limit is untested
<!-- labels: task, eval-set -->

**Type:** Task · **Priority:** Low · **Repository:** global-bank-account

## Description

`Money.MAX_POSTING_MINOR` exists and is enforced, but no test covers it. A refactor could remove the
check tomorrow, and every test would stay green.

## Acceptance criteria

1. A posting above the limit is rejected, and a test proves it.
2. A posting exactly at the limit is accepted, and a test proves it.
3. The tests check the effect on the ledger, not only that no exception was thrown.
