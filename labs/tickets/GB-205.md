# GB-205 — Same reference, different amount

**Labels:** `bug` `priority: high` `eval-set`

## Description

The payroll feed sent two instructions with the same `clientReference` and the same `valueDate`, but
different amounts. The second one was accepted as a new posting.

Operations are not sure which of the two is correct. They want the service to stop getting this wrong.

## Acceptance criteria

1. The same reference and value date with a different amount no longer creates a silent second posting.
2. Behaviour for real duplicates is unchanged.
3. Covered by tests.
