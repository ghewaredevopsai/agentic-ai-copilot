Dataclasses — records without the boilerplate, and one trap1

VALUE OBJECT AND MUTABLE RECORDfrom dataclasses import dataclass, field @dataclass(frozen=True, slots=True) class Money: amount: Decimal currency: str def add(self, other: "Money") -> "Money": return Money(self.amount + other.amount, self.currency) @dataclass class Ticket: title: str priority: int = 3 watchers: list[str] = field(default_factory=list) def __post_init__(self): if not 1 <= self.priority <= 4: raise ValueError("priority must be 1..4")

What you get, what you don’t

  • Generated: __init__, __repr__, __eq__ — equality compares values.
  • frozen=True — assignment raises. Hashable, safe to share.
  • __post_init__ is where your rules live.
  • No type checking. Money("10", 5) still constructs.
  • self is explicit, always the first parameter.
The trap: watchers: list = [] would share one list between every Ticket. dataclasses refuses that literal; = None slips through. Use default_factory.

What to know when you read them

  • Importing runs the file. Top-level code runs once, on first import.
  • Nothing is private. _name is a convention only.
  • Circular imports fail at once. Layers point one way: models ← store ← search ← api.
  • if __name__ == "__main__": guards code that runs only as a script.
  • pip install -e . puts your package on the path.

One base class, raise specific, catch narrow2

A DOMAIN HIERARCHYclass AskOpsError(Exception): """Everything AskOps raises on purpose.""" class RunbookNotFound(AskOpsError): def __init__(self, runbook_id: str): super().__init__(f"runbook {runbook_id} not found") self.runbook_id = runbook_id # store.py, inside class Store def get_runbook(self, runbook_id): try: return self._runbooks[runbook_id] except KeyError: raise RunbookNotFound(runbook_id) from None

Rules that survive review

  • EAFP: try the lookup and catch KeyError. Do not check first.
  • No checked exceptions. The hierarchy is the contract.
  • raise X from exc keeps the cause; from None hides it.
  • Translate at the edge. The store raises RunbookNotFound; only the API makes it a 404.
  • Let TypeError crash. That one is a bug.
Block on sight: except:, except Exception: pass, and except Exception that returns a normal-looking result.

  • Waiting on I/O (httpx, an async database driver)? Use async def and await.

TestClient and dependency overrides — no server, no mocking library3

a fresh store for every test# tests/conftest.py @pytest.fixture def client(store): # this test's own store app.dependency_overrides[get_store] = lambda: store with TestClient(app) as c: yield c # teardown runs after yield app.dependency_overrides.clear() def test_unknown_runbook_is_404(client): r = client.get("/api/runbooks/RB-999") assert r.status_code == 404 assert "RB-999" in r.json()["detail"] def test_ask_is_503_when_a_source_fails(client, store): app.dependency_overrides[get_store] = \ lambda: WikiDown(...) r = client.get("/api/ask?q=deploy") assert r.status_code == 503

Why this design

  • Every test gets a fresh store, so no state leaks.
  • A failure path is one subclass away. No mocking framework.
  • yield in a fixture means setup, then teardown.
  • Runs in milliseconds, in process, in CI.
This is why the spec says no module-level store. A global cannot be overridden, so the agent shortcut would break every test.

A Python PR checklist — what you look for, in order5

Correctness — the Python traps

  • Mutable defaults — =[] in a def; a dataclass list field set to None, not default_factory
  • Truthiness hiding a real 0; is used for values
  • Blocking I/O in async def; awaits not gathered
  • Swallowed failures — except that returns a normal result
  • Unbounded input — a limit with no cap

Design — the house rules

  • Domain errors translated only at the edge
  • pydantic v2 only
  • No module-level state; use Depends
  • logger with %-args, never print
  • HTML through templates, never f-strings
  • User input never in a host, path or SQL
  • Tests unchanged, or changed for a stated reason
Put this list in .github/copilot-instructions.md so the agent reads it too — then review anyway.
