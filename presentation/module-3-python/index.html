The tests are the spec. python score.py prints a [PASS]/[FAIL] line per check and a score. Copilot writes all the code; you direct it, read it and decide. Every lab tells you what "done" means — exactly how you will direct an agent at work. Fall behind, and AskOps has a checkpoint tag for every mission, so you can start the next one green; solutions/ shows the Copilot prompts behind each one.

What this module covers, and what it does not

This module is about the Python. The language as an experienced engineer needs it, the FastAPI service stack, and reviewing Python that an AI wrote. GitHub Copilot is used throughout — a tutor prompt, a house-rules file, agent mode — but its features are not taught in depth here.
Out of scope, deliberately. Packaging for distribution, databases and ORMs, typing beyond reading hints, and LLM calls. AskOps' /ask is keyword search on purpose: it is the seam where an agent brain goes next.
