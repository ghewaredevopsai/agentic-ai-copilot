From the standard library, not a framework

from collections import Counter, defaultdict

Counter("deploy deploy rollback".split())
# Counter({'deploy': 2, 'rollback': 1})

by_service = defaultdict(list)
for inc in incidents:
    by_service[inc.service].append(inc.id)
  • Tuples are values, lists are containers. A tuple can be a dict key
  • Sets make membership O(1) — if tag in tags
  • Reach for collections before writing a helper

Unpacking, enumerate and zip are the lines engineers from other languages most often misread at speed. Read them out loud once.

Comprehensions

filter + map + collect, in one readable line

Written like Java

titles = []
for i in incidents:
    if i.severity == "high":
        titles.append(i.title)

Written like Python

titles = [i.title for i in incidents
          if i.severity == "high"]
ShapeComprehensionGives you
list[x.id for x in items if x.open]a new list
dict{x.id: x for x in items}an index by id

Review rule: one for and one if reads well. Two nested fors plus a condition is a loop pretending to be clever — ask for the loop back.

The generator row matters later: next(iter(x), default), any(...) and all(...) all take generators, and the first_or_default drill depends on it.

None, truthiness, type hints

What counts as false, and what the hints do not do

Truthiness

# falsy: None  False  0  0.0  ""  []  {}  set()
name = user.get("name") or "anonymous"   # idiomatic

if not retries:        # BUG when 0 is a real value
if retries is None:    # say what you mean
  • None is one object: compare with is
  • x or default is fine for strings, risky for numbers

Type hints

def search(store: Store, query: str,
           limit: int = 5) -> list[Hit]: ...

owner: str | None = None      # not Optional[str]
counts: dict[str, int] = {}
  • Read by your editor, Copilot, mypy, FastAPI and pydantic
  • Ignored by the interpreter: search(store, 42) runs until it breaks
  • That gap is why tier 3 validates at the edge

If you have ever shipped a bug where 0 or an empty string meant "missing", Python makes that bug one keyword away.

Dataclasses

Records without the boilerplate — and the one trap

Value object and mutable record

from dataclasses import dataclass, field

@dataclass(frozen=True, slots=True)
class Money:
    amount: Decimal
    currency: str
    def add(self, other: "Money") -> "Money":
        return Money(self.amount + other.amount, self.currency)

@dataclass
class Ticket:
    title: str
    priority: int = 3
    watchers: list[str] = field(default_factory=list)
    def __post_init__(self):
        if not 1 <= self.priority <= 4:
            raise ValueError("priority must be 1..4")

What you get, what you don't

  • Generated: __init__, __repr__, __eq__ (value equality)
  • frozen=True — assignment raises. Hashable, safe to share
  • __post_init__ is where invariants live
  • No validation of types. Money("10", 5) constructs
  • self is explicit, always the first parameter
The trap: watchers: list = [] would share one list between every Ticket. dataclasses refuses the literal; = None slips through. Use default_factory.

This is the pattern in askops/models.py, which you read in Lab 2, and in the Money and Ticket drills in Lab 1.

def breach_minutes(incidents, sla_minutes=None):
    """Minutes past SLA, per incident id."""
    sla = sla_minutes or 60
    return {i.id: i.open_minutes - sla
            for i in incidents
            if i.open_minutes - sla > 0}

def worst(incidents):
    breaches = breach_minutes(incidents)
    return max(breaches, key=breaches.get) if breaches else None

"Returns the incident furthest past SLA. Pass sla_minutes=0 for strict mode."

Decide before you discuss

  • Does strict mode work?
  • What does max(breaches, key=breaches.get) return: a number, or an id?
  • Would you ask for the comprehension to be a loop?
