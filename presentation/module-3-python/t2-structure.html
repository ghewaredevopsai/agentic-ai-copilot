Modules and packages

A file is a module, a folder is a package

The AskOps layout

askops/                # repo root
  pyproject.toml
  askops/              # the package
    __init__.py
    models.py          # dataclasses
    errors.py          # exceptions
    store.py           # imports models
    search.py          # imports store
    api.py  web.py     # HTTP edges
    app.py             # wires it up
  tests/
    conftest.py        # shared fixtures
    test_m2_core.py

What to know when reading imports

# stdlib first, then third party, then yours
import logging
# absolute imports - prefer them
from askops.models import Incident, Severity
# or the module itself
from askops import sources
  • Importing runs the file. Top-level code executes once, on first import — keep it to definitions
  • No access modifiers. _name means "private by convention"; nothing enforces it
  • Circular imports fail at import time. Layers point one way: models ← store ← search ← api
  • if __name__ == "__main__": is the main() guard — code that runs only as a script
  • Editable install (pip install -e .) puts your package on the path, like a module on the classpath

Dependency direction matters in review: an import of askops.api inside store.py, added to reuse a helper, is a layering violation and often a circular import waiting to happen.

Exceptions

One base class, raise specific, catch narrow

A domain hierarchy

class AskOpsError(Exception):
    """Everything AskOps raises on purpose."""

class RunbookNotFound(AskOpsError):
    def __init__(self, runbook_id: str):
        super().__init__(f"runbook {runbook_id} not found")
        self.runbook_id = runbook_id

def get_runbook(self, runbook_id):
    try:
        return self._runbooks[runbook_id]
    except KeyError:
        raise RunbookNotFound(runbook_id) from None

Rules that survive review

  • EAFP: try the lookup, catch KeyError — no containsKey first
  • No checked exceptions. Nothing forces a caller to handle anything; the hierarchy and docstrings are the contract
  • raise X from exc keeps the cause in the traceback; from None hides it
  • Translate at the edge. The store raises RunbookNotFound; only the API turns it into 404
  • except AskOpsError for failures you expect. Let TypeError crash: that is a bug
Block on sight: except:, except Exception: pass, and except Exception that returns a normal-looking result.

An AI asked to "make it resilient" reaches for except Exception more often than anything else. Lab 5 comes back to it.

with, logging, decorators

Three constructs you will read on every page

with — cleanup, guaranteed

with open(path, encoding="utf-8") as fh:
    data = json.load(fh)
# closed here, even on exception

with httpx.Client() as c: ...
with lock: ...

try-with-resources / using. Any object with __enter__ / __exit__ works.

logging — not print

logger = logging.getLogger(__name__)

logger.warning("skipping %s: %s", rid, exc)
logger.exception("ask failed")
# ERROR + the traceback

One per module. %-args, not f-strings: formatted only if emitted.

Decorators — functions that wrap

def timed(fn):
    @functools.wraps(fn)
    def wrapper(*args, **kwargs):
        t = time.perf_counter()
        try:
            return fn(*args, **kwargs)
        finally:
            took = time.perf_counter() - t
            logger.debug("%s %.3fs", fn.__name__, took)
    return wrapper

@timed
def search(...): ...

@router.get, @pytest.fixture, @dataclass: every framework decorator is this pattern — a function that takes yours and returns something better.

*args, **kwargs means "any positional and any keyword arguments". The timed decorator is Lab 2's stretch goal.

pytest in one slide

Plain assert, fixtures by name, parametrize

import pytest

# conftest.py - available to every test, no import
@pytest.fixture
def store():
    return Store.from_dir(DATA_DIR)

def test_missing_runbook_raises(store):          # injected by name
    with pytest.raises(RunbookNotFound, match="RB-999"):
        store.get_runbook("RB-999")

@pytest.mark.parametrize("value", ["0", "65536", "http"])
def test_invalid_port(value):
    with pytest.raises(ValueError):
        parse_port(value)

def test_bad_record_logged(tmp_path, caplog):      # built-in fixtures
    (tmp_path / "incidents.json").write_text("[...]")
    ...
    assert "INC-2" in caplog.text

Why it matters today

  • The tests are your spec for every mission
  • Plain assert: pytest rewrites it to show both sides on failure
  • tmp_path, caplog, monkeypatch come free
  • pytest -x stops at the first failure; -k name runs one
The rule for agents: a test is changed by a human, on purpose. An agent that edits a test to go green gets its diff rejected.

Fixture injection by parameter name looks like magic if you are used to annotations. It is a lookup: pytest reads the function signature.
