Words used in this moduleM5

LangChain words

  • Chat model — one model endpoint, wrapped.
  • Prompt template — a prompt with blanks to fill.
  • Output parser — turns the reply into data.
  • LCEL — join parts with a pipe: a | b.
  • Runnable — any part you can join.
  • Chain — runnables joined in a fixed order.

LangGraph words

  • State — one shared dictionary.
  • Node — a function that updates the state.
  • Edge — which node runs next.
  • Reducer — how an update joins a key.
  • Checkpointer — saves the state after each node.
  • Thread — one conversation’s saved states.
  • Interrupt — pause and wait for a person.

Chain, agent or graph? Pick the smallest1

Choose in this order

  • Chain: you know every step.
  • Agent: the model picks the steps.
  • Graph: you need to control the steps, save them or pause them.
Same test as Module 4: can you draw the flowchart first?

A graph is a flowchart you can run2

graph.pyclass State(TypedDict): messages: Annotated[list, add_messages] kind: str tries: int g = StateGraph(State) g.add_node("classify", classify) g.add_node("search", search) g.add_node("answer", answer) g.add_edge(START, "classify") g.add_edge("classify", "search") g.add_edge("search", "answer") g.add_edge("answer", END) graph = g.compile()
  • A node returns only what it changes.

Conditional routing and cycles2

graph.pydef route(state): return state["kind"] g.add_conditional_edges("classify", route, {"runbook": "search", "incident": "list_incidents"})
  • A router returns the next node’s name.
  • A cycle is an edge back to an earlier node.
  • recursion_limit is the backup stop.

Checkpointers: save every step, remember each session2

graph.pygraph = g.compile( checkpointer=InMemorySaver()) cfg = {"configurable": {"thread_id": "eng-a"}} graph.invoke(inputs, cfg) graph.get_state(cfg)
  • Same thread_id: same conversation.
  • A crash loses nothing that was saved.
  • InMemorySaver is for labs. Production uses a database.

What to take from Module 5M5

Keep these

  • LangChain parts replace your Day 1 code, not the loop.
  • Pick the smallest: chain, agent, graph.
  • Nodes return only their changes. Reducers join them.
  • Every cycle needs a stop rule in the state.
  • Checkpointer + thread_id: memory and resume.
  • interrupt before any tool that writes.
