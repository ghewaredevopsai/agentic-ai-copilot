Words used in this moduleRAG

Storing knowledge

  • RAG — retrieve text, then generate the answer.
  • Chunk — a small piece of a document.
  • Embedding — text turned into a list of numbers.
  • Vector — that list of numbers.
  • Vector store — a database that finds close vectors.
  • Collection — one named set of chunks in Chroma.

Searching and remembering

  • Top-k — the k best matches.
  • BM25 — keyword search that ranks exact words.
  • Hybrid retrieval — keyword and vector search together.
  • Reranker — scores the best results again, carefully.
  • Grounded — every claim comes from the given text.
  • Eviction — removing old memories by a rule.

RAG is two pipelines1

Embeddings: meaning as numbers2

What an embedding is

  • An embedding model turns text into a vector.
  • Similar meaning, so the vectors point the same way.
  • Cosine similarity measures that angle. 1.0 means the same direction.
  • Real vectors have hundreds of numbers. This picture shows 2.
Rule: one embedding model for chunks and questions.

Chunks and metadata: what you store decides what you find2

Three ways to split

  • Fixed size + overlap — simple.
  • By heading, then paragraph — the usual default.
  • By topic change — costs more.

Size

  • Too small loses context. Too big mixes topics.
Metadata lets you filter, cite and control access.

Hybrid retrieval: meaning plus exact words3

How to merge

  • RRF (reciprocal rank fusion): add 1 / (60 + rank) from each list.
  • Only ranks count, so no score tuning.
Module 3’s keyword search stays. It gets a partner.

Rerankers: search wide, then read closely3

Why two stages

  • The retriever is fast, but rough.
  • A reranker reads question and chunk together.
  • Cross-encoder: a small model that scores each pair.
  • LLM: send all 20, ask for the best 3.

Cost

  • Adds delay. The LLM also costs tokens.
  • Fewer chunks in the prompt, so fewer answer tokens.

Agentic RAG: retrieval becomes a tool4

Fixed chain or agent

  • Fixed chain: one search every time, even for “hello”.
  • Agentic RAG: the model decides whether, where and how often to search.

Module 4 rules still apply

  • A limit on searches per run.
  • Every search counts in the cost per run.

Long-term memory: what to write, what to forget4

Write

  • Save confirmed facts, preferences and incident outcomes.
  • Never save guesses, secrets or personal data.

Evict

  • Time to live: expires after a set time.
  • Least recently used: goes first when full.
  • On request: privacy rules need it.
